## Kiến trúc: Layered Architecture

```
Controller Layer  ← tiếp nhận HTTP request
      ↓
Service Layer     ← business logic (xương sống)
      ↓
Repository Layer  ← giao tiếp database (JPA)
      ↓
Database (MySQL)  ← lưu trữ
```

### Dependency Direction

- **controller** → service, dto
- **service** → repository, entity, dto, exception, util
- **repository** → entity
- **config**, **security**, **exception** — đứng riêng, không phụ thuộc layer nào
- **entity** — không phụ thuộc gì

### Luồng request mẫu

```
GET /api/students
  → StudentController.findAll()
    → StudentService.getAllStudents()
      → StudentRepository.findAll()
        → SELECT * FROM students (MySQL)
      ← List<Student> (Entity)
    ← List<StudentDTO> (DTO)
  ← JSON response
```

## Nội dung đã học (bước này)

1. **Vì sao cần chia package**: tránh rối, dễ maintain, dễ test, dễ reuse.
2. **Layered Architecture**: controller → service → repository → DB, mỗi tầng chỉ gọi tầng dưới.
3. **Cách tổ chức trong công ty**: package-by-layer (cho dự án vừa) vs package-by-feature (cho dự án lớn).
4. **Vai trò từng package**: controller (nhận request), service (logic), repository (DB), entity (bảng), dto (truyền dữ liệu), config (cấu hình), security (bảo mật), exception (lỗi), util (tiện ích).
5. **Chiều dependency**: chỉ từ trên xuống dưới, không import ngược.
6. **Luồng request**: Client → Controller → Service → Repository → DB → ngược về Client.

## Nội dung đã học (Step 3 — Entity)

| Annotation / Khái niệm | Entity được dùng | Ý chính |
|---|---|---|
| `@Entity`, `@Table` | Student, Course, Enrollment, User | Đánh dấu class là entity, chỉ định bảng |
| `@Data`, `@NoArgsConstructor`, `@AllArgsConstructor`, `@Builder` | Cả 4 entity | Lombok: sinh getter/setter/constructor/builder |
| `@Id`, `@GeneratedValue(IDENTITY)` | Cả 4 entity | Khoá chính tự tăng cho MySQL |
| `@Column(name, nullable, length, unique, precision, scale, columnDefinition)` | Cả 4 entity | Mapping field → cột với ràng buộc |
| `@PrePersist`, `@PreUpdate` | Cả 4 entity | Callback tự gán createdAt/updatedAt |
| `@ManyToOne(fetch = LAZY)`, `@JoinColumn` | Enrollment | Quan hệ nhiều-1, giữ FK |
| `@OneToMany(mappedBy, cascade, orphanRemoval)` | Student, Course | Quan hệ 1-nhiều, phía không giữ FK |
| `@ToString.Exclude`, `@EqualsAndHashCode.Exclude` | Student, Course | Tránh StackOverflow khi log entity có quan hệ vòng |

## Lỗi người mới hay gặp — tổng kết

1. **Import `javax.persistence` thay vì `jakarta.persistence`** (Spring Boot 2 vs 3).
2. **Dùng `int` / `long` thay `Integer` / `Long`** → không phân biệt được chưa lưu.
3. **Dùng `double` cho tiền** → sai số làm tròn (dùng `BigDecimal`).
4. **Quên `@NoArgsConstructor`** → Hibernate crash.
5. **Quên `LAZY` trên `@ManyToOne`** → `EAGER` mặc định → chậm.
6. **Quên `@ToString.Exclude` trên collection** → StackOverflowError.
7. **Quên `updatable = false` trên `createdAt`** → mất thời gian gốc khi update.
