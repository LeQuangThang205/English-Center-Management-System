## Vấn đề gặp phải và cách giải quyết

1. **Schema-validation: missing table [classes]**
   - `application.yml` có `ddl-auto: validate` → Hibernate validate H2 (empty DB) → fail
   - Fix: tạo `src/test/resources/application.yml` với `ddl-auto: create-drop`

2. **Cascade delete không hoạt động**
   - `User.studentProfile` không được set (null) → cascade REMOVE không kích hoạt
   - Fix: set `user.setStudentProfile(profile)` trong test `@BeforeEach`

## Kiến thức đã học (Step 4)

1. **Root Cause Analysis** — đọc stack trace, tìm exception gốc, cascade failure mechanism
2. **@DataJpaTest** + **H2** — slice test cho JPA repository
3. **@AutoConfigureTestDatabase(replace = Replace.NONE)** — dùng DB thật cho test
4. **Bidirectional relationship** — luôn set cả 2 chiều để cascade hoạt động
5. **ddl-auto** — `validate` (production) vs `create-drop` (test)
6. **Schema first design** — ưu tiên schema.sql khi code và schema mâu thuẫn
