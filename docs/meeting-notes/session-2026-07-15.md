## 2. Các Quyết Định Đã Chốt

### Bất di bất dịch (Hard Constraints)

| Quyết định | Lý do |
|------------|-------|
| Đây là **đồ án tốt nghiệp**, không phải sản phẩm thương mại | Mục tiêu đồ án |
| **3 role cứng**: Admin, Teacher, Student | Không thêm Staff, Manager, Counselor |
| AI là **tính năng hỗ trợ**, không phải trọng tâm | Giảm scope cho đồ án |
| **Web Application only** — không Mobile App | Giới hạn nền tảng |
| **Monolithic** — không Microservices | Kiến trúc |
| **Spring Boot + React + MySQL** | Công nghệ cố định |
| Thanh toán: "ít nhất 1 cổng trực tuyến", không ghi tên cụ thể | Tránh phụ thuộc vendor |

### Phạm vi AI

| Trong scope | Ngoài scope |
|------------|-------------|
| Chatbot trả lời FAQ, khóa học, học phí, lịch học | Chấm bài tự luận |
| Gợi ý khóa học theo mục tiêu học viên | Xếp lớp tự động |
| Dashboard Assistant phân tích dữ liệu hội thoại | Đánh giá đầu vào |
| | Machine Learning Training |

### Use Case Relationships đã chốt

- `Approve Registration` <<include>> `View Registration Detail` (bắt buộc)
- `Reject Registration` <<include>> `View Registration Detail` (bắt buộc)
- `Browse Courses` <<extend>> `View Course Detail` (tùy chọn)
- `Process Registration` (general) → `Approve Registration`, `Reject Registration` (specialized)
- `Make Payment`, `Chat with AI`, `Get Course Recommendation`, `Use AI Dashboard Assistant`, `Send Notification` — secondary actors nối trực tiếp, **không** dùng include
