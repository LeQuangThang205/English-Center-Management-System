### 2. Thanh toán (UC-26)

Đồ án sử dụng hình thức **QR chuyển khoản thủ công**.

Workflow:

1. Student chọn đăng ký đã được duyệt.
2. Hệ thống hiển thị mã QR và thông tin chuyển khoản.
3. Student thực hiện chuyển khoản bằng ứng dụng ngân hàng.
4. Student nhấn **"Đã thanh toán"**.
5. Admin đối chiếu Internet Banking.
6. Admin xác nhận thanh toán.
7. Hệ thống cập nhật:
   - Registration → **PAID**
   - Transaction → **SUCCESS**
   - Student được thêm vào lớp.

Không tích hợp Payment Gateway, webhook hoặc callback.

#### Hoàn thành

| Database Creation Test | `DROP DATABASE` + chạy lại `schema.sql` — không lỗi | ✅ Pass |
| DDL Review | Review report — PASS (20 tables, 25 FK, 10 UK, 8 CK, 15 ENUM) | ✅ |

#### Chi tiết

- Tất cả 20 bảng được tạo từ Physical Database Design v1.0.
- 25 Foreign Key với cascade rules đúng:
  - `ON DELETE CASCADE`: bảng phụ thuộc (registration_details, score_details, v.v.)
  - `ON DELETE SET NULL`: bảng tham chiếu (created_by, updated_by, approved_by, deleted_by)
  - `ON DELETE RESTRICT`: bảng tham chiếu khóa (users.id, courses.id, classes.id)
- Tất cả `ON DELETE SET NULL` columns đều là `NULL` (không `NOT NULL`).
- MySQL Warning duy nhất: `Integer display width is deprecated (TINYINT(1))` — không ảnh hưởng.
- 10 Unique Constraints bao gồm: `username`, `email`, `phone`, `slug`, `class_code`, `transaction_code`, `faqs.question`, `enrollments`, `attendance_details`, `score_details`.
- 8 Check Constraints bao gồm: `gender`, `status` (users, courses, classes, registrations), `payment_method`, `transaction_status`, `score_value`.
