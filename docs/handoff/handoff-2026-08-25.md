## Backend contract (không thay đổi)

- `GET /api/scores?studentId={id}` — STUDENT: own only; TEACHER: all for assigned classes
- `POST /api/scores` — create (teacher only)
- `PUT /api/scores/{id}` — update (teacher only, class must be STUDYING/FINISHED)
- ScoreResponse: `{id, studentId, studentName, classId, className, courseName, midtermScore, finalScore, totalScore, comment, createdById, createdByName, createdAt, updatedAt}`
- Total auto-computed: `mid*0.4 + fin*0.6`, scale 1 HALF_UP
